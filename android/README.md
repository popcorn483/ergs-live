# ERGS Live for Android

A small Android app that opens [ERGS Live](https://popcorn483.github.io/ergs-live/) full screen using Chrome (a Trusted Web Activity). Everything on the website works the same, including Google sign-in for coaches and players.

GitHub builds it automatically (`.github/workflows/android.yml`) whenever anything in this folder changes, and publishes `ERGS-Live.apk` to the repository's Releases.
