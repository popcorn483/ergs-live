# ERGS Live

Live scores, fixtures and results for Enniskillen Royal Grammar School rugby. Supporters need no account; coaches sign in with Google to score.

- `index.html`, `app.js`, `crest.js`: the page
- `config.js`: Firebase settings and the admin's email
- `fb.js`: the live database connection
- `firestore.rules`: paste into Firebase → Firestore → Rules
- `seed.json`: matches brought across from the Claude version (used once, by "Set up the scoreboard")
- `app/`: the ERGS Rugby main app (tactics, squads, graphics, team of the week), at https://popcorn483.github.io/ergs-live/app/
